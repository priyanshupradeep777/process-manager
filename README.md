# Process Manager (CLI Tool)

A simple command-line based Process Manager built in Python using the `psutil` library.  
This tool helps users list running processes, view system information, and terminate processes manually.

---

##  Features

- View all running processes (PID, Name, CPU usage, Memory usage)
- View system information  
  - CPU Cores  
  - CPU Usage  
  - Total RAM  
  - RAM Usage  
- Kill a process by entering its PID
- Simple and interactive CLI menu

---

##  Technologies Used

- **Python 3**
- **psutil** library
- Linux command-line interface
